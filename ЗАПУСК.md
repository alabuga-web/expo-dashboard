# Запуск — кратко

## Быстрый старт (один экран производства + данные из БД)

Данные ПЛК подхватятся из `back/plc_data.db` (режим replay). Бэк OPC не обязателен.

Если нужна свежая демо-история производства (цвета, склад, FX5), сначала:

```bash
cd back
python3 seed_demo_db.py
```

```bash
cd front
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)

| Экран | URL |
|-------|-----|
| Производство | `/production` |

Нужен `sqlite3` в PATH (для чтения `plc_data.db`).

---

## Live-данные с pipeline API (WebSocket)

Пайплайн FactoryIO (этот репозиторий) отдаёт live через FastAPI:

- REST: `http://localhost:8080`
- WebSocket: `ws://localhost:8080/ws`

```bash
cd front
PLC_API_URL=http://localhost:8080 \
NEXT_PUBLIC_PLC_API_URL=http://localhost:8080 \
npm run dev
```

Экраны `/production` и `/process` подписаны на WS (`useLiveData`): обновление по событиям, при обрыве — polling.

Приоритет источников: **live WS/API** → **replay из БД**.

---

## Live-данные со старым OPC-стеком `back/` (опционально)

```bash
cd back
./stack.sh dev          # симулятор + Kafka + backend :8000
```

```bash
cd front
PLC_API_URL=http://localhost:8000 \
NEXT_PUBLIC_PLC_API_URL=http://localhost:8000 \
npm run dev
```

UI бэка: [http://localhost:8000](http://localhost:8000)

---

## Переменные окружения (front)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `PLC_API_URL` | `http://localhost:8080` | REST backend (server) |
| `PLC_WS_URL` | derive from `PLC_API_URL` | Server-side WS bridge |
| `NEXT_PUBLIC_PLC_API_URL` | `http://localhost:8080` | Browser → derive WS |
| `NEXT_PUBLIC_PLC_WS_URL` | derive | Browser WebSocket |
| `PLC_DB_PATH` | `../back/plc_data.db` | Путь к SQLite replay |
