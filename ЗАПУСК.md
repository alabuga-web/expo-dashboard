# Запуск — кратко

## Быстрый старт (один экран производства + данные из БД)

Данные ПЛК подхватятся из `back/plc_data.db` (режим replay). Бэк OPC не обязателен.

Если нужна свежая демо-история производства (цвета, склад, FX5), сначала:

```bash
cd back
python3 seed_demo_db.py
```

```bash
cd front
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)

| Экран | URL |
|-------|-----|
| Производство | `/production` |

Нужен `sqlite3` в PATH (для чтения `plc_data.db`).

---

## Live-данные с OPC (опционально)

```bash
cd back
# нужны .env.dev / .env.prod (уже в репо; иначе: cp .env.example .env.dev)
./stack.sh dev          # симулятор + Kafka + backend :8000
# или
./stack.sh prod         # реальный ПЛК (нужна сеть, см. setup_network.sh)
```

UI бэка: [http://localhost:8000](http://localhost:8000)

Затем Dashboard:

```bash
cd front
PLC_API_URL=http://localhost:8000 npm run dev
```

Приоритет источников: **live API** → **replay из БД**.

Live-конфиг OPC уже расширен под Vision/COLOR, сортировку, склад и FX5.

---

## Переменные окружения (front)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `PLC_API_URL` | `http://localhost:8000` | Бэк в каталоге `back/` |
| `PLC_DB_PATH` | `../back/plc_data.db` | Путь к SQLite |

## Полезное

```bash
# Сгенерировать демо-БД производства
cd back && python3 seed_demo_db.py

# Только CLI-опрос ПЛК → запись в БД
cd back && ./run_opc.sh

# Остановить Docker-стек
cd back && ./stack.sh down
```

Подробнее: `back/ARCHITECTURE.md`, `back/ОПИСАНИЕ_ДАННЫХ.md`.
