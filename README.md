# Expo Dashboard

`expo_dashboard` — это демо-проект производственной панели для выставочного стенда Alabuga. Репозиторий объединяет фронтенд-витрину, backend для чтения данных из PLC / Factory I/O и документацию по тегам, данным и запуску.

## Что показывает проект

Основной пользовательский сценарий — один экран `/production`, на котором отображаются:

- выпуск изделий по цветам;
- текущее состояние линии и конвейеров;
- активность сортировки;
- состояние склада по направлениям;
- движение манипулятора FX5 Pick & Place;
- live-данные с OPC или replay из SQLite.

Проект подходит для двух режимов работы:

1. **Demo / replay** — фронт берет историю из `plc_data.db`, заранее подготовленную скриптом `seed_demo_db.py`.
2. **Live OPC** — backend читает реальные или симулированные OPC UA теги и отдает их в API / WebSocket.

## Структура репозитория

- `front/` — Next.js dashboard, основной UI и API-роуты для фронта.
- `back/` — backend, OPC UA listener, Kafka/SQLite pipeline, Docker-стек, генерация демо-данных.
- `Tags_S7-1500.xlsx` — исходный список PLC-тегов S7-1500.
- `ЗАПУСК.md` — краткая инструкция по запуску.

## Как связаны части проекта

Поток данных выглядит так:

1. PLC / Factory I/O публикует сигналы через OPC UA.
2. Backend в `back/` считывает теги, сохраняет историю и отдает последние значения.
3. Frontend в `front/` агрегирует сырой поток в понятные карточки и графики для экрана производства.
4. Если live-источник недоступен, фронт может читать replay из локальной SQLite-базы.

## Основные данные

В проекте используются несколько типов сигналов:

- **датчики** — наличие детали, проход через зону, обнаружение коробки;
- **исполнительные механизмы** — конвейеры, сортировщики, захват;
- **vision / color** — код цвета и типа детали;
- **координаты FX5** — фактические позиции и уставки манипулятора;
- **служебные теги PLC** — heartbeat, системные флаги, шаги автоматов.

Подробное описание всех тегов из `Tags_S7-1500.xlsx`, сгруппированное по устройствам, находится в `back/ОПИСАНИЕ_ДАННЫХ.md`.

## Документация

- `ЗАПУСК.md` — как поднять demo и live-режим
- `back/ОПИСАНИЕ_ДАННЫХ.md` — понятное описание всех тегов и данных
- `back/ARCHITECTURE.md` — устройство backend и потока данных

## Что важно знать

- Главный экран проекта: `/production`
- Источник данных по приоритету: **live API -> replay SQLite**
- Excel-файл `Tags_S7-1500.xlsx` — это первичный справочник сигналов, из которого собраны человеко-понятные описания для проекта
